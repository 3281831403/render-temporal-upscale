# 时域超分历史状态修复（高难度）

## 题面

开时域超分后，静态画面很锐、一动就拖影，切镜头还残留上一镜：时域超分把亚像素抖动、历史颜色、历史深度和累积权重串成一条状态链，十个缺陷依次是——抖动序列退化为固定 (0,0)，超分退化成普通放大；重投影沿 +motion 正向采样，历史错位半像素到整像素，静态区域也发糊；历史深度校验用绝对差阈值，近处误判、远处漏判；blend 的 alpha 不按像素归一，权重和不为 1，亮度随历史长度漂移；accumulate 把新深度写成当前帧深度，和历史用的重投影深度不一致，下一帧校验全部失败而自我失效；converge_weight 把 1/(n+1) 直接乘到颜色上，而不是当作混合权重，颜色偏向历史、收敛到错误值；reset_on_cut 只重置颜色不重置深度，切镜头后深度仍是旧值；jitter 的序列周期等于 8，与 60Hz 显示器形成拍频；validate_state 不检查历史与深度的尺寸一致，导致越界；accumulate 对无效历史像素仍以极小权重参与混合，产生鬼影。关键是历史的三件事要同步：颜色、深度、权重；错一件就自我失效。tupscale/accumulate.py 是核心，tests/test_accumulate.py 15个红。要修的是：让抖动序列确定且不形成 8 帧拍频、重投影方向正确、深度校验按相对尺度、混合权重逐像素归一、累积深度与历史一致、收敛权重参与混合而非缩放颜色、切镜头同时重置颜色/深度/权重、状态校验覆盖尺寸/NaN/权重和，并彻底排除无效历史像素。

## 运行方式

在仓库根目录执行：

```text
python -m pytest tests -q
```

初始状态必须是恰好 `15 failed`，不能出现 collection、import 或语法错误。15 条测试全部调用 `tupscale/accumulate.py` 的公开桩，因此初始失败是预期结果；修复实现后才应转绿。

约束：只用标准库（`math`）和 `pytest`，离线运行，不使用随机数。

## 状态数据

颜色、深度和运动矢量都是行优先的 `list[list[...]]`，形状为 `(height, width)`。历史是同样形状的记录网格，每个记录为 `{"color": float, "depth": float, "weight": float}`。`weight` 在 `[0, 1]` 内；颜色和深度不做预乘。所有函数应是纯函数，不修改入参，浮点比较容差为 `1e-9`。

## 测试不可修改

`tests/test_accumulate.py` 是契约，15 条测试不可修改、不可删除、不可跳过。不要把断言改弱，也不要通过修改测试来制造绿色；应修复 `tupscale/accumulate.py`，并保持 8 个公开函数的签名与文档约定。
